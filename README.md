# claude-energy-public

Static site that hosts the Claude Code energy tracker dashboard at <https://energy.bexodim.com>.

The dashboard (`index.html`) is generated by `energy_tracker.py` in the parent `claude-energy/` directory:

```
python3 energy_tracker.py --csv --dashboard
cp energy_dashboard.html claude-energy-public/index.html
```

Commit and push to update the live site.
